# 12属性の構成と確定事項 v0.2

## 決定事項

ユーザーの「1.A、2.A」により、下記12種類の名前と分類、および穏やかな旅立ちから始まる序章が確定した。
属性倍率と複合属性の計算方式も確定済み。具体的な全相性、技や特性への割り当ては提案。
旧資料の「12属性の名前は未確定」という記述より、この文書を優先する。

## 確定した属性一覧

| 属性 | 扱う力・イメージ | デザインへの展開例 |
|---|---|---|
| 無 | 基礎的な力、体の動き、特定の力へ偏らない性質 | 身近な動物、汎用的な戦い方 |
| 草 | 植物、芽吹き、生命の成長 | 花、葉、根、つぼみ |
| 炎 | 火、熱、燃焼 | 炎、熱を蓄える部位 |
| 水 | 水、流れ、潮 | ひれ、水流、波を扱う部位 |
| 雷 | 電気、稲妻、放電 | 電気をためる模様や器官 |
| 氷 | 冷気、氷、凍結 | 冷たい被膜、氷結する部位 |
| 地 | 土、岩、砂、地形 | 掘る前足、硬い外皮、岩質 |
| 風 | 風、空、飛行 | 翼、風を受ける体、滑空 |
| 鋼 | 金属、硬い鉱質、強い構造 | かたい外殻、刃状の器官 |
| 毒 | 毒、腐食、体内で作る刺激性の物質 | 毒袋、分泌器官、警戒色 |
| 光 | 光、幻光、浄化 | 発光、きらめき、幻のような模様 |
| 闇 | 影、夜、幻惑 | 影に溶ける輪郭、夜行性の表現 |

光・闇は力の性質として扱い、種族の善悪や性格を固定する分類にはしない。
竜・虫などは生物の系統・モチーフとして表現し、属性との組み合わせで個性を作る。土・岩・砂は地、空・飛行は風へまとめる。
打撃・斬撃・射撃などは技の表現・分類として整理する案。

## 御三家との関係

- 草の系列：ハナミミ → ハナリット → フロレーヌ。
- 炎の系列：ホノル → フレイガ → グレンヴァル。
- 水の系列：ミオマル → ナミグマ → タイドガル。
- 初期形はそれぞれの基本属性を一つ持つ案。
- 最終形を単属性にするか複合属性にするかは、相性表と役割を見て決める。
- 華やかな見た目だから必ず光、竜の姿だから必ず専用属性、という自動割り当てはしない。

## 相性の最初の案

草は水に強い、水は炎に強い、炎は草に強い、という三すくみを基本案とする。
他の相性も、ゲーム内の説明や技の見た目と結びつけて理解できるものを優先する。

- 確定した倍率は有利2倍、通常1倍、不利0.5倍、一部無効0倍。
- 最大2属性の積を使うため、4倍・0.25倍も生じる。
- [全相性表の初稿](13_type_matchup_proposal_v0.1.md)を作成した。個別の相性はまだ提案。
- 12×12の相性表を作り、攻撃側と防御側の意味を統一して管理する。
- 有利や耐性の多さだけで一部の属性へ偏らないか、技・能力・特性と合わせて確認する。
- 相性の意図的な例外を設ける場合は、説明と役割を記録する。

## 育成・対戦の奥深さ

覚える属性数を抑え、技、交代、状態変化、特性、持ち物、2対2の連携で選択肢を作る。
本編は基本の組み合わせで進み、クリア後に編成・継承・個体調整を深められる設計を維持する。
タイプの一致による補正、技の分類、補助効果の確率、同じ状態の重ね掛けは別に定義する。

## UIの検討

属性は色と名前とアイコンを併用する案。色だけに判断を依存させない。
技の選択時に、分かっている相手への有利・不利を表示するかを決める。
図鑑やヘルプから相性表へ戻れ、初めての対戦で学んだ情報を後から確認できるようにする。

## 次に決めること

1. 全相性表の個別の組み合わせと、独自の相性の分かりやすさ。
2. 御三家の最終形を含む、種族ごとの複合属性と役割。
3. 相手の属性と相性を、最初から見せるか、遭遇・図鑑の進行で明らかにするか。
