# 全素材の制作台帳と規格案 v0.1

この台帳は必要な制作範囲と現在の不足を整理したもの。全素材を完成させた一覧ではない。
対象は本編とクリア後を含むゲーム全体。図鑑は150種以上、156種は引き続き初期案。

## 現在あるファイル

| 対象 | 制作状態 | 次に必要なもの |
|---|---|---|
| 御三家初期・最終6体 | 造形方向採用・比較原画あり | 各体の設定画、前後、アイコン、必要な動作 |
| 御三家中間3体 | 原画提案 | 造形の確認、設定画、取り込み用素材 |
| 一般種6体 | 造形方向採用・比較原画あり | 設定画、前後、アイコン、進化系列の設計 |
| フィールド | 見下ろし方向の参考画像あり | 地形・建物の分割素材、継ぎ目、衝突・重なりの情報 |
| 12属性の相性 | 144組のJSONを試作用採用 | 技・種族と合わせた実装後の調整 |

## 全体をそろえるための制作範囲

| 区分 | 必要なデータ・素材 | 現在の不足 |
|---|---|---|
| 全種族 | 系統図、安定ID、属性、能力値、技、特性、図鑑、出現・入手条件 | 全150種以上の詳細は未設計 |
| モンスター画像 | 各種の戦闘前面・背面・アイコン、必要な動作、希少色の定義 | ゲーム規格での仕上げは未制作 |
| 人物 | 主人公の選択肢、ライバル、重要人物、一般NPC、歩行・表情 | 人物一覧と素材は未制作 |
| 地域・マップ | 全地域のつながり、配置、建物、地形、屋内、イベント、後から戻る秘密 | 最初の地域の構成案まで。全体のマップデータは未制作 |
| 技・特性・道具 | 安定ID、説明、数値、効果、対象、習得・入手条件、必要な演出 | 全件のデータと演出は未制作 |
| 物語 | 章構成、台詞、選択肢、フラグ、報酬、再挑戦・取り逃し回収 | 中心設定と序章案まで。全編の会話・イベントデータは未制作 |
| 音 | 地域・街・戦闘・強敵・イベントのBGM、効果音、使用場面、ループ | Sunoでの生成とゲーム取り込み用の仕上げは未実施 |
| UI | 属性・状態・道具アイコン、ウィンドウ、メニュー、図鑑、文字規則 | 画面構成と画像の詳細は未制作 |

156種を採用し前面・背面・アイコンを各1点作るなら、静止素材だけで468点になる計算。
これは規模の見積もり。最終的な種数や必要なアニメーション数、画像ファイルをまとめる方法は別に決める。

## 量産前に確認する規格案

| 素材 | 出発点 | 少数での確認 |
|---|---|---|
| 地形 | 論理32×32pxのタイル | 道・草・水・岸・角の接続、繰り返し、衝突 |
| 人物 | 論理32×48px、4方向×3フレーム | 足元、歩幅、頭身、実画面での読みやすさ |
| モンスター | 論理96×96pxの枠を基準 | 前後の同一性、翼・尾の収まり、体格差、余白 |
| アイコン | 論理32×32px | 種族・進化段階を見分けられるか |
| 音 | 保管用原本と取り込み用圧縮ファイルを区別 | 音量、開始・終端、ループ、実機での再生 |
| データ | JSONと安定ID、版番号 | 参照切れ、進化条件、全種の一人用入手経路 |

全て初期案で、まだ量産用の確定規格とはしない。画面の基準解像度・UIの占有率も少数の表示で確かめて決める。
原画に描いた小さな文字やボタンをそのままゲームUIとして使わない。

## 台帳の制作状態

- 未設計：必要な内容自体をまだ決めていない。
- 提案：候補を作った状態。
- 造形採用：見た目の基準として採用した状態。
- 取り込み用制作済み：必要な寸法・向き・透過・ファイル形式で出力した状態。
- 確認済み：実際の表示・接続・再生で確認した状態。

採用原画があることと、取り込み用素材があることを分けて記録する。
既存ファイルのID・パス・ハッシュは[実ファイル台帳](asset_inventory_v0.1.json)にも記録した。
クラウド準備パックでは同じ内容をmanifests/assets.jsonに置き、tools/validate_assets.pyでファイルの存在・ハッシュ・PNGの基本情報を確認できる。
その検査は美術品質・本編の完成・実機互換性の検証を代替しない。

## 直近の作業

まず全種の系統・全地域・主要人物・物語の一覧を具体化し、素材数を見積もる。
並行して少数の画像と音で規格を確認し、確定した単位から全体の素材を制作する。
地域・進化系列ごとの進行は台帳に残し、Claude Codeクラウドへ渡す時点で不足が見えるようにする。

変更履歴：v0.1 素材を全体で先に準備するための範囲・不足・規格確認を整理。
