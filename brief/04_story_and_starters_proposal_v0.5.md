# 物語・幼なじみ・最初の相棒3体の提案 v0.5

位置づけ：事件の方向を採用し、幼なじみの動機を設計担当の判断で決定した更新版。
確定：育成補助技術の普及と各地の異変を、大会へ挑む旅と結びつける。
担当決定：幼なじみは二人で決勝に立つ約束を守りたいという焦りから、勝利を急ぐ。ユーザーから動機の設計を任されている。
造形の希望：最近のポケモンに通じる親しみやすさ・かわいさへ寄せる。種族そのものはオリジナルとする。
相棒のモチーフ・名前・属性・進化形、事件の細かな演出は引き続き案。新しい画像の最終採用は未確定。
背景・ゲーム内表示は、既に決めた見下ろし型の2Dドット絵で進める。

## 1. 物語の中心

「いつか二人で、あの決勝の舞台に立つ」

子どもの頃、主人公と幼なじみは地方大会を見て約束した。
10代後半になった二人は、それぞれ最初の相棒を迎えて旅立つ。
主人公は各地の人や生き物と出会いながら強くなる。
幼なじみは約束を実現するため、負けない育て方を研究し、結果を急ぐようになる。

二人が最後に向き合うのは、「一緒に決勝へ行く」約束を、互いの歩みを認めて実現できるかという問い。
大会へ挑む動機は旅の最後まで保ち、事件解決後に大会を置き去りにしない。
本編は、事件の決着と大会の頂点への挑戦の両方を描いて終える。

## 2. 各地の事件：育成端末と観測塔

### 人々の暮らし

相棒の動きや体調、得意な技を記録して、育成を助ける端末が普及し始めている。
道具を使った研究、繁殖、特性や技の組み合わせの工夫も、この世界で大切にされる。
主人公も同じ育成の便利機能を使える。

### 異変

各地の観測塔を一斉に同期させる、新しい運用が始まる。
ところが、その信号は地域ごとに違う野生モンスターの活動周期へ影響してしまう。
これは本作の架空の生態設定であり、現実の生物に関する説明ではない。

- 昼間の森で、夜行性の群れが落ち着かず道をふさいでいる。
- 川辺の生物が繁殖地へ戻らず、水門付近に集まっている。
- ある谷では、進化直前の個体が同じ場所を行き来している。

最初は地域の小さな困り事として体験し、旅を進めると同じ原因が見えてくる。
地域の代表に挑む過程で観測施設へ近づき、大会の道のりと事件を自然につなげる。
代表戦の勝利だけで異変が解決するのではなく、調査・探索・協力を組み合わせる。

### 誰が対立するのか

観測事業の責任者は、育成が便利になった成功例を信頼し、地域差の報告を軽く見ている。
問題が大きくなる中でも、大会に合わせた本格運用を急ごうとする。
会社名、責任者の人物像、敵組織を登場させるかは未確定。
明確な悪役を求める場合は、危険を把握して隠している人物を設定する方向へ調整できる。

### 決着

古い観測記録と各地の生態を調べ、地域ごとに信号の周期を調整する方法を見つける。
主人公と幼なじみは別々の施設を担当し、途中で合流して協力する。
地形の謎を解き、能力持ちの仲間で進み、終盤の2対2で協力する。
最後は人や相棒の様子を見ながら装置を使う運用へ改め、各地は落ち着きを取り戻す。

## 3. 幼なじみの動機と成長

### 採用する動機と人物像

- 主人公と同じ故郷で育った、同年代の幼なじみ。
- 負けず嫌い。自分から先を目指し、実力で認められたい。
- 昔の小さな大会では、緊張して実力を出せず、主人公との約束を果たせなかったことがある。
- 今度こそ約束を守りたいという焦りから、勝つ方法を数値や記録に求める。
- 主人公が寄り道しながら成果を上げる姿に、置いていかれる不安を覚える。
- 相棒には愛情があり、勝利のために相棒を捨てたり傷つけたりすることを人物像の前提にしない。

性別、名前、外見、家族構成は未確定。
主人公との関係は友情を軸にする案。恋愛要素は現時点で設定しない。

### 戦い方の変化

| 時期 | 行動・編成で表現すること |
|---|---|
| 序盤 | 素直な攻撃と相性重視。結果に一喜一憂する |
| 中盤 | 勝ち筋を絞った戦術。計画が崩れると立て直しが遅い |
| 衝突後 | 記録を見直し、相棒それぞれの得意な役割を発見する |
| 協力戦 | 味方を助ける技や交代を使い、主人公と連携する |
| 大会 | 攻撃・補助・交代を組み合わせ、個性のある強敵になる |

装置利用を理由に、告知していない能力補正をライバルへ与えない。
戦闘の強さは通常のルール、編成、技、特性、判断で表現する。
クリア後は主人公と育成情報を共有し、繁殖・再育成施設への導線を担う案。

## 4. 大きな流れ

| 場面 | 物語 | プレイヤーが遊ぶ内容 |
|---|---|---|
| 序章 | 約束、相棒との出会い、旅立ち | 相棒選び、初戦、捕獲、最初の小さな依頼 |
| 前半 | 地域ごとの困り事と、ライバルとの競争 | 代表戦、地形パズル、昼夜の遭遇 |
| 中盤 | 各地の異変のつながりが見える。二人の考えが衝突する | 過去の場所の再探索、分岐進化のヒント |
| 後半 | 記録と現地の観察を合わせて原因へ近づく | 観測施設、探索能力の使い分け、強敵 |
| 事件の決着 | 二人が協力して運用を改める | 遺跡の仕掛け、施設攻略、特別な2対2 |
| 大会 | 約束した舞台で互いの成長を確かめる | ライバル戦と頂点への挑戦 |
| 結末 | それぞれの次の目標を見つけ、故郷で再会する | 拠点の発展、クリア後への導入 |
| クリア後 | 古い記録の背景と、生息域の広がりを知る | 追加エリア、希少種、繁殖・継承・再育成 |

本編だけで事件と人物の主要な疑問へ答える。
任意の探索では、昔の研究者や生態をより深く知れる構成にする。
クリア後に初めて分かる秘密は、本編で起きたことの意味を豊かにする。

## 5. 伏線と回収

| 序盤で見えるもの | 本編での理解 | クリア後の発見 |
|---|---|---|
| 村の古い風見が昼夜で向きを変える | 過去の観測方法と関係している | 観測の周期が特殊進化のヒントになる |
| 橋の下の、読めない古い標識 | 昔の生息域への道しるべ | 水上移動で隠された繁殖地へ進める |
| 拠点の古い写真に残る小さな生物 | 今も地域にいる種とのつながり | 特殊条件の進化形を知る手掛かりになる |

必要な情報はゲーム内に置き、外部攻略サイトを前提にしない。
写真や標識は後から再確認できる。イベントを飛ばしても重要な手掛かりは冒険メモへ残す。
特殊進化や希少種の具体的な条件は未確定。

## 6. 最初の相棒：特別感を重視した新案

ユーザーの好みは、初期形がニャオハ・ポッチャマのようにかわいく、最終形がリザードン・カメックスのように強そう、またはサーナイトのように華やかであること。
3候補とも初期形と最終形の両方で魅力があることを重視する。
前案の甲獣・炉鳥・舟尾イモリは、御三家としての特別感が不足するという指摘を受け、採用を保留する。

[御三家の造形再設計](06_starter_signature_design_brief_v0.2.md)を最新の基準として参照する。
[新しい比較画像](starter_concepts_v0.4.png)は上段が初期形、下段が最終形。どちらの段階も主役らしい魅力を目指す。

| 系列 | 初期形 | 最終形の方向 |
|---|---|---|
| A・草の案 | つぼみの尾を持つ花兎 | 大きく流れる花弁を持つ、華やかな精霊獣 |
| B・炎の案 | 小さな翼を持つ仔竜 | 巨大な炎形の翼と、力強い体を持つ翼竜 |
| C・水の案 | 小さな波形の前腕を持つ子熊 | 波の盾と重厚な腕を持つ、頼もしい海の守護獣 |

初期・最終の原画と3系列の方向は造形の基準として採用。ゲーム用素材の仕上げはこれから。
[進化と名前](07_starter_evolution_plan_v0.1.md)で中間形を提案し、名前は担当が決定した。[12属性の構成案](08_type_system_draft_v0.1.md)も用意した。
具体的な相性、数値、技、前後左右の設定画、ドット絵化は未確定。
選ばなかった2系列も一人で後から入手でき、必須探索能力は通常種からも得られる条件を維持する。
物語の主要な筋と委任された幼なじみの動機は、今回の造形変更によって変更しない。

## 7. 序章の会話例

以下は人物の口調を確認する例であり、確定した台詞ではない。
本番では主人公の名前・見た目・選んだ相棒・戦闘の勝敗を差し込む。

### 選択肢の形

幼なじみ：
「やっとだな。……あの決勝、今度は客席から見るんじゃない。」

主人公の選択肢：

- 「先に行って、待ってる。」 → 幼なじみ「言ったな。置いていかれるなよ。」
- 「最後まで、一緒に行こう。」 → 幼なじみ「……ああ。そのために強くなる。」
- 「まずは、この子と仲良くなる。」 → 幼なじみ「お前らしいな。俺は、一つ勝ってくる。」

どの選択も旅立ちへ合流する。
選んだ言葉は、後の再会時の短い会話に反映する案。入手種・結末・必須報酬は分けない。

### 中盤の衝突

幼なじみ：
「記録では、もう勝てるはずだった。練習だって、足りてる。」
「……お前は、どうしてそんなふうに進めるんだよ。」

主人公の返答は、励ます・勝負で確かめる・相棒の様子を一緒に見る、の3方向を案とする。
主な物語は合流し、返答によって直後の短い行動や会話を変える。

### 大会での再会

幼なじみ：
「約束、やっと本当になるな。」
「ここまで来たんだ。最後まで、勝ちにいくぞ。」

## 8. 実装へ渡すときの確認

1. 通常系：3候補のどれを選んでも、序章・ライバル・大会の会話に矛盾がない。
2. 境界系：初戦で勝つ・負ける、会話を早送りする、任意の遺跡を見ない場合も、本編を理解して進められる。
3. 障害系：イベントの途中で中断・再開しても、相棒の二重受取、会話フラグの食い違い、進行不能が起こらない。
4. 連続性：主人公の返答が違っても決勝への主要な導線は一致し、選択に応じた会話差分が残る。
5. 収集：どの相棒選択からでも、他候補と必要な探索能力を一人で得られる。

これは設計上の確認項目。ゲーム本体による実行検証は未実施。
