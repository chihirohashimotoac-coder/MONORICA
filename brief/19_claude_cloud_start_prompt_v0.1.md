# GitHubの素材をClaude Codeクラウドへ引き継ぐ指示 v0.1

現在は素材準備段階。この指示は、素材一式をGitHubへそろえて本格実装を開始するときに使う。

## 素材準備中にクラウドで点検だけ依頼する場合

```text
CLAUDE.md、brief/17_cloud_asset_first_workflow_v0.1.md、brief/18_asset_inventory_v0.1.md、manifests/assets.jsonを読んでください。
python3 tools/validate_assets.pyを実行し、現在あるファイルと、全体に必要な未制作素材を分けて報告してください。
今回は素材の準備と規格確認を進めます。一般種6種と御三家初期・最終の造形採用を引き継ぎ、採用済みの方向を聞き直さないでください。
```

## 素材がそろって本格実装を依頼する場合

```text
素材の準備を踏まえて、ゲーム本体の実装を開始してください。
CLAUDE.mdとbrief/02_claude_code_cloud_prompt_v0.1.mdを読み、旧ローカル環境向けの開始手順よりクラウド版を優先してください。
manifests/assets.jsonと実ファイルを照合し、未制作・提案・採用原画・取り込み用素材・確認済みを区別してください。
全体条件を維持し、brief/15_claude_first_region_prompt_v0.2.mdの段階A～Dを、現在のGitHubリポジトリ内で順に実装してください。新たにWindowsのローカルフォルダを開く手順は不要です。
まず最初の地域を動かし、捕獲・探索技・町の代表戦・レベル16進化・保存後の再開を確認してください。その後、本編とクリア後を段階的に完成させてください。
数値・素材の調整が必要な点は、具体的な理由と対象ファイルを示して相談してください。既存契約以外の追加課金は前提にしないでください。
```

一式を作った後も、実際の遊びやすさ・プレイ時間・長時間動作は実装したゲームで確認する。
GitHubへの登録やClaude Codeへの投入は、今回の準備パック作成では実行していない。
