# 素材確認帳

依存パッケージ不要。リポジトリのルートで次を実行する。

```sh
cd /workspace/MONORICA
python3 -m http.server 8765 --bind 127.0.0.1
```

ブラウザでそのサーバーの`/tools/asset-review/`を開く。クラウド環境で直接ブラウザを接続できない場合は、対応するブラウザツールから内部確認するか、展開済み一式を手元で同じように起動する。外部公開や未対応のプレビュー機能は不要。

記録済みの原画・設定画7枚と個別候補3枚の切り替え、ローカルPNGの読み込み、背景色、1・2・4・8倍、外周・基準点・格子の表示ができる。寸法・透明ピクセル・外周余白を照合する。素材候補を選んだら規格案も選ぶ。歩行の接地や前後の同一性は目視で確認する。

ゲーム本体・マップ実装・音声再生・実機確認の代わりではない。台帳や採用状態への書き込み、画像のアップロード、外部API接続は行わない。

戦闘の向きは同じサーバーの`/tools/asset-review/battle-composition.html`で確認できる。同じ試作を両側に置く静的な配置例で、ゲーム本体ではない。

`/tools/asset-review/sprite-candidates.html`では、候補3点を1倍と整数倍、透過チェック・濃紺・草地色で比較できる。原寸は96px・32px。候補を素材確認帳で選ぶと規格も自動で切り替わる。

戦闘UIは日本語ドット字体とひらがなコマンドの新案へ更新した。表示にはローカル同梱のDotGothic16を使い、外部通信は不要。`content/ui/`のJSONと`battle-ui.js`が編集元。UIの見た目の確認画面で、戦闘処理は含まない。

最新の設定画はホノルv0.2（独立腕2・脚2・翼2）とミオマルv0.1。旧ホノル4肢案には不採用ラベルを付けている。採用済みのUI枠も切り替えて確認できる。

御三家初期3体をsprite-candidates.htmlで切り替えられる。ホノル・ミオマルの静止素材は見た目採用済み。battle-composition.htmlでは味方と相手を選択でき、名前・画像だけを変更する。ゲームの戦闘や交代処理ではない。

御三家初期3体の9枚と戦闘UI枠に続き、一般種3体のドット素材9枚も採用済みへ更新した。

リスコロ・ツルモグ・ハネリの個別PNG候補9枚を追加し、比較と戦闘表示で6体を選択できる。一般種9枚も「3体ともこのまま採用」と回答済み。高解像度原画は素材確認帳で別に参照できる。

後続のミズッタv0.1・ココイルv0.1・ヨルミルv0.2の前後横設定画は新しい見た目の確認待ち。素材確認帳で選べる。ヨルミルの旧6肢案v0.1には不採用ラベルを付け、四肢へ修正したv0.2と区別する。設定画は参照資料であり、96pxのruntime素材ではない。
