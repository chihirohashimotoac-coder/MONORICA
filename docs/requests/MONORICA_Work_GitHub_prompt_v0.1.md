## 3. 設計レビューと修正

全156種を読んで、次を具体的に確認し、必要な制作案を修正してください。

- 部位の本数と接続、前・背・横の整合、96px・32pxで残す特徴の具体性
- 各地域の生態・発見・属性・戦闘役割・入手時期の偏り
- 御三家の選択を補う通常種、全種の一人用入手、進化条件の再現可能性
- 必須探索技の入手前後関係、条件の循環、忘却・預け入れ・帰還への設計上の配慮
- 本文の相性説明と試作用相性表からの計算結果の一致
- 既存の採用範囲と新規提案の混同

まず問題を特定し、そのまま安全に修正できる制作案の修正・再検査まで進めてください。計画や問題一覧だけで止まらないでください。
確認済みの条件を変える必要がある重大な矛盾は、根拠と選択肢をまとめて確認してください。名前や未採用モチーフを一体ずつ質問する必要はありません。

新規内容をユーザー採用済みへ変更せず、変更理由と差分を残してください。

- ちょうど156種。進化形は別種、色違い・姿勢・美術版差分は加算しない。
- 元の配分：御三家9／カザミ12／ミナセ18／ヒノワ18／カナト18／ツキシロ18／サナギ18／アカツキ15／ホシミ12／シズナ9／メグリ9。
- 本編8地域・代表8人・クリア後2地域。12属性はcontent/type-chart.jsonを使う。
- 既存15種のID・名前を維持し、known-species.jsonを156体へ置き換えない。
- ハナミミ→ハナリット→フロレーヌ、ホノル→フレイガ→グレンヴァル、ミオマル→ナミグマ→タイドガル。Lv16・36進化。
- 他の御三家2系列は本編クリア後に一人で両方を取得。通常種からも必要地点前に探索技を取得できる。
- 探索技は戦闘4枠の1枠を使い、実際に覚えた個体を手持ちへ入れる。
- 通信・対人・限定配布・課金・外部サービスを必須にしない。
- ホノル系列は独立腕2・脚2・背翼2。ID内のwyvernを理由に4肢へ戻さない。
- ヨルミル系列は前脚2・後脚2、飛膜は手首から足首。独立翼・追加脚なし。
- runtime PNG19枚は既存採用済みのまま。ミズッタv0.1・ココイルv0.1・ヨルミルv0.2の新三面設定は確認待ち。ヨルミル旧v0.1は不採用。
- 新規141種と既存種への詳細追加は制作案。数値種族値・技威力を検証済みの確定値として作らない。
- 画像生成、ドット絵制作、ゲーム本体実装、公開は今回行わない。
