## 6体についての訂正
新画像6種の保存登録は002ハナリット・003フロレーヌ・005フレイガ・006グレンヴァル・008ナミグマ・009タイドガルです。001〜006という範囲ではありません。
GitHubには別の9種の設定画（001,004,007,010,012,014,016,018,020）があり、合計15種には画像または保存参照があります。これらを再生成から外し、残る141種を割り当てました。保存参照のあることは、全画像本体の再取得確認・見た目の採用完了を意味しません。
セッション1は既存画像の保全も担当します。3種の設定画確認待ち、6新画像の本体未検証の状態を保持し、取得できない画像を黙って完成扱いにしません。

## 同時実行を安全に進めるための構成
- 全5本が同じ設計スナップショット b6c1d875e3f624bb77d1e632bfed561380d7ed19 を使用。
- 進化系列をセッション間で分断しない。
- 自分専用ブランチだけへ保存。元ブランチ・PR #2・共通台帳・LATEST_HANDOFF.mdは更新しない。
- 1種ごとに生成とGitHub保存・画像本体の読み戻しを完了。最初の1種で保存経路を実証してから後続を制作。
- 各セッションの結果は候補・確認待ち。採用済みに変更せず、runtimeも変更しない。
- 全体統合は各セッション終了後の別工程。5本とも自動マージしない。
- ユーザー確認は全体がそろってから。取得不能な既存画像があれば、その不足は別に明示。
