# ホノル・ミオマル：前後横の設定画案

2026-11-02。戦闘UI v0.1の見た目をユーザーが採用した後、残る御三家初期2体の設定画を制作。採用済み`brief/starter_concepts_v0.4.png`を参照し、元原画は保持した。

## ホノル：独立した腕2・脚2・背中の翼2

[最新の設定画 v0.2](../assets/source/monsters/starter_ember_wyvern_01/model_sheet_v0.2.png)

旧資料の腕と翼の不一致を確認したところ、ユーザーは「独立した腕2本・脚2本・翼2枚にしたい」と回答した。これを優先し、**6肢構造を制作上の決定**とする。最初に描いた翼が前肢を兼ねる4肢案は不採用。

v0.2では、腹の左右に短い赤い腕と小さな暗色の手を付け、足は地面に着く太い2本、翼は腕の後ろの背中から生える構造へ分離した。中央の背面でも翼の付け根と小さな手が別に見える。

保持した特徴：幼い丸い竜の顔、橙色の目、暗色の巻いた角と橙色の先端、赤と象牙色の体、胸の太陽形の印、橙の翼膜、太い脚、短い赤い尾。

確認したい細部：小さな手の大きさ、腕と翼の前後関係、背面の腕の明るい部分。構造の6肢採用と、今回の補完形状や塗りの採用を区別する。

ホノル系列の中間形・最終形にも、腕と翼が独立する構造を一貫させる設計方針とする。中間形・最終形の新しい設定画やドット絵はまだ制作しておらず、既存の採用原画を黙って置き換えない。

`starter_ember_wyvern_01`というIDのwyvernは以前からの文字列。保存・参照を壊さないためIDを改名しない。今後の制作で、IDから4肢構造を推定しない。

旧`model_sheet_v0.1.png`は不採用の経緯として保持し、台帳にv0.2への置き換え先を記録した。描き起こしの基準にはv0.2と最新の6肢指定を使う。

## ミオマル：波形の裏側と小さな尾

[設定画 v0.1](../assets/source/monsters/starter_tide_bear_01/model_sheet_v0.1.png)

丸い子熊、青い目、濃紺の丸い耳と手足、象牙色の口元と腹、胸の波模様、小さな前腕の波形を維持。最終形のような重い肩や巨大な盾へ成長させない。

前腕の波形は、持っている道具ではなく、腕の外側につく器官として裏側の接続を描いた。背面には小さな丸い青い尾を補っている。原画で見えなかった尾や背中の形は、今回の提案であって採用済みとはしない。

確認したい細部：小さな尾、前腕の波形の大きさ、背面の丸み。腹の波模様を背中へ追加しない。

## 向きと素材の状態

2体とも左から「前3/4・後3/4・横」。設定画の正面は元原画と同じ右向き、背面は戦闘の味方側に合う右上向き、横は左向き。**戦闘用の前面は出力時に左下向きへそろえる。** 設定画の右向きを、そのまま戦闘前面の向きとしない。

全設定画は1983×793のRGB PNGで、透過なし。96pxの取り込み用スプライトではない。2体のモデルシートの採用後に、ハナミミと同じドット絵の雰囲気・細かさで前面96・背面96・アイコン32へ展開する。

実際の生成指示は`docs/prompts/honoru_model_sheet_v0.1.txt`（不採用の4肢案）、`honoru_six_limb_model_sheet_v0.2.txt`（6肢へ修正）、`miomaru_model_sheet_v0.1.txt`。旧4肢指示を最新の仕様として再利用しない。

今回の素材追加は設定画3枚（ホノル旧案・修正版・ミオマル案）。モンスターの取り込み用PNGはハナミミ3枚のまま。採用した戦闘UI枠をruntimeへ登録したため、UI込みの取り込みPNGは4枚。
