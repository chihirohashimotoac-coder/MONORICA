# 参考画面に寄せた戦闘UIとひらがな表記 v0.1

2026-11-02。ユーザーの「戦闘配置での表示、特にUIはポケモンに酷似」「基本はひらがなのUI」を反映した表示を提示後、「問題ありません」と回答。**v0.1の枠・配置・色・字体・主コマンドの見た目を採用**した。ゲーム本体や実機での最終レイアウトまで実装・検証した意味ではない。

## 表示案

[3倍の表示画像](../reports/battle-ui_v0.1.png) ／ [原寸384×256](../reports/battle-ui_native_v0.1.png)

- 参考画面と同じ、相手情報は左上、味方情報は右下。味方背面は左下、相手正面は右上。
- ステータス欄は淡いクリーム色、濃いオリーブ色の太い段付き枠と影。
- 下部左側は濃紺の会話欄と金色寄りの縁、右側は明るい2×2コマンド欄。
- 選択中のコマンドは黒い三角カーソル。HPは緑、経験値は青のバー。
- 草地の楕円と細い水平線の背景。文字も画像もドットの粒が見える描画にする。

現時点の基準画面は384×256、文字は16pxのグリッドを出発点にする。これはモンスター素材96pxを変更する指示ではなく、UIの構図確認用の寸法案。味方は画面上で手前に拡大し、操作欄の後ろで下部が隠れる。元の全身PNGを切り捨てない。

この3:2の表示領域をスマートフォン横持ちの利用可能範囲にどう収め、左右の十字キー・決定・キャンセルと組み合わせるかは、本体実装で検証する。現在の確認ページを、そのまま実機用の最終レイアウトとはしない。

## 文言

| 以前の表示 | 今回の表示 |
|---|---|
| ハナミミの行動は？ | ハナミミは／どうする？（2行） |
| 技 | たたかう |
| 持ち物 | どうぐ |
| 交代 | なかま |
| 逃走 | にげる |

操作案内はひらがなを基本にする。固有名の「ハナミミ」などはカタカナを維持し、HP・Lv・数字など必要な略号は併用。会話の漢字量や固有名まで一律にひらがなへ改名する意味ではない。

文言は`content/ui/battle-ui-ja.json`へ分離。「わざを えらんでね」「もどる」「つかう」「やめる」など、後続画面で使える語も用意した。これらの画面や戦闘処理を実装したわけではない。
