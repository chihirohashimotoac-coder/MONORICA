# 序盤一般種：最初の3体の設定画案

2026-11-02。御三家初期3体の静止素材が採用されたため、序盤一般種の採用原画を前後横へ展開した。今回はリスコロ・ツルモグ・ハネリ。元の`brief/wild_monsters_concepts_v0.1.png`は変更していない。

**一般種の造形方向は以前から採用済み。今回補った背面・横面や器官の接続は、新しい設定画案として確認する。** 作業名・属性案・進化先・能力値までこの制作で確定しない。

## リスコロ

[前・後・横の設定画案](../assets/source/monsters/wild_seed_squirrel_01/model_sheet_v0.1.png)

大きな尾、琥珀色と象牙色の体、明るい茶色の目、木の実を抱える姿を維持。背面と横面では、腰の後ろから生える**1本の尾**が連続する構造として補完した。種房のような大きな丸いふくらみを、別々の尾として分岐させない。

正面では巻いた尾の内外が両側に見えるため、後ろの付け根と横の曲線を合わせて見る。尾先の薄緑の葉形の模様を残し、持っている木の実を背中へ追加しない。

確認点：尾の曲がり方と付け根、3つの大きな丸いふくらみが1本として自然に見えるか。木の実を持つ姿は原画を引き継いだ設定で、ゲーム中の持ち物システムを固定する意味ではない。

## ツルモグ

[前・後・横の設定画案](../assets/source/monsters/wild_vine_mole_01/model_sheet_v0.1.png)

低く横へ広い体、大きな象牙色の前足、小さな後ろ足、穏やかな目と鼻を維持。頭の大きな葉2枚と、**腰から生える1本のつたの尾＋先端の小さな二股の葉**を別の器官として描いた。

確認点：尾の付け根、後ろ足の小ささ、背面でも大きな前足が同じ体につながって見えるか。人の腕や追加の前足を生やさず、低いモグラの姿を保つ。

## ハネリ

[前・後・横の設定画案](../assets/source/monsters/wild_breeze_bird_01/model_sheet_v0.1.png)

青緑と象牙色の羽、珊瑚色の肩、黄色いくちばし、後ろへ流れる冠羽、広い扇尾を維持。**翼2枚・脚2本・腰から広がる1つの扇尾**を各視点でつなげた。手のような別の腕は追加しない。

確認点：扇尾の付け根、青緑と象牙色が交互に並ぶ羽、翼と肩の珊瑚色の位置。姿勢によって羽が重なって見えるため、見えている羽先の数だけで別の構造へ変えない。
